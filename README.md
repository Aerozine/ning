# NbN Experimental Project

This folder is organised around the NbN experimental project and the final A0 portrait poster.

- `postpro/`: raw data copies, processing scripts, and generated CSV summaries.
- `plot/`: generated PDF/PNG plots used in the poster.
- `researchproposal/`: research proposal sources, bibliography, logos, and original proposal PDF.
- `poster/`: Typst poster source and final compiled poster PDF.

Run the full workflow from this directory with:

```sh
make
```
